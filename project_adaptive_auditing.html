Adaptive auditing of AI systems with anytime-valid guarantees

Siyu Zhou*, Patrick Vossler*, Venkatesh Sivaraman, Yifan Mai, Jean Feng
NeurIPS 2026
[paper] [code] [back to publications]

Summary

When auditing an LLM, practitioners often probe for failure modes using small, adaptively chosen test suites of 10–50 cases, where which cases to annotate next depends on past results. Classical statistics forbids this — the usual sample-size and sampling-scheme assumptions are violated. We ask: can we draw rigorous conclusions about model robustness from fully adaptive audits with as few as 20 observations?

We propose formalizing an audit as two dueling hypothesis tests — a model's null (no failure mode exists in any subgroup of prevalence ≥ ε) and an auditor's null (this specific strategy would eventually find one) — and testing both using e-processes, which provide anytime-valid Type I error control under arbitrary adaptive sampling and optional stopping.

Model's perspective — no failure mode exists

\(H_0^{\mathrm{mod}}:\ \forall S \in \mathcal{S}_\epsilon,\ V(S) \geq q\)

\(H_1^{\mathrm{mod}}:\ \exists S \in \mathcal{S}_\epsilon \text{ s.t. } V(S) < q\)

Rejecting this null means the AI system is not globally robust.

Auditor's perspective — my audit will find one

\(H_0^{\mathrm{aud},[m]}:\ \exists \tau \in [m],\ \forall t \geq \tau,\ V(S_t^\pi) < q\)

\(H_1^{\mathrm{aud},[m]}:\ \forall \tau \in [m],\ \exists t \geq \tau \text{ s.t. } V(S_t^\pi) \geq q\)

Rejecting this null means the AI system passed this specific audit.

Here \(\mathcal{S}_\epsilon\) is the collection of subgroups with prevalence at least \(\epsilon\); \(V(S)\) is average accuracy on subgroup \(S\); \(q\) is the target performance threshold; \(S_t^\pi\) is the subgroup selected by the auditor's adaptive strategy \(\pi\) at step \(t\); and \(m\) is the auditor's budget. If the auditor is asymptotically consistent, Theorem 1 of the paper shows these two nulls become complements as \(m \to \infty\) — the audit then becomes a true binary certification of robustness.

Try it yourself: find the LLM's blind spot

Imagine an LLM is being tested on GPQA-style science questions. Each question has a domain (Biology, Chemistry, Physics) and an education level (Undergraduate, Graduate, Post-graduate). We fixed the LLM's performance across the 9 strata, but only one stratum is a true failure mode. Your job: find it using as few annotations as possible, and let the e-process tell you when you have enough evidence to reject the model's null.

We test the model's null \(H_0^{\mathrm{mod}}: \forall S \in \mathcal{S}_\epsilon,\ V(S) \geq q\) using the fixed-alternative likelihood-ratio e-process (Option 1 of §3.2.1): \(E_t = \prod_{k=1}^{t} p(Y_k;\, q{-}\delta) / p(Y_k;\, q).\) Reject when \(E_t \geq 1/\alpha\). Scores are binary (correct / incorrect).

Target threshold q = 0.80, alternative q−δ = 0.50, significance level α = 0.05 (reject when Et ≥ 20).
